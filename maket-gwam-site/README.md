# 모형곰 (maket.gwam) 사이트

캐릭터와 AI 숏폼을 만드는 모형곰의 고객용 사이트와 관리 화면이에요. 설치나 빌드 없이 `index.html`을 열면 돼요.

## 여는 법

| 화면 | 여는 법 |
| --- | --- |
| 고객 화면 | `index.html` |
| 관리 화면 | `index.html#admin` (Netlify에 올렸다면 `주소/#admin`) |

Claude 앱 안에서는 편집 권한이 있는 계정으로 열면 자동으로 관리 화면이 나와요.

## 관리 화면에서 할 수 있는 것

- **눌러서 바꾸기**: 관리 화면 → "고객 화면 보기" → 위쪽 "✎ 눌러서 바꾸기". 로고, 카테고리 아이콘, 배너 이미지, 상품 사진, 샘플 썸네일, 이야기 탭의 대표 브랜드 사진을 누르면 사진 목록이 그림으로 떠요. 고르면 바로 저장돼요.
- **글꼴**: 미리보기 위쪽 "글꼴" 버튼, 또는 브랜드 설정 → 글꼴. 제목과 본문을 따로 골라요.
- **사진 고르기**: 상품·샘플·배너·로고 칸의 "바꾸기"를 누르면 같은 사진 목록이 떠요.
- **샘플 순서**: 출품·납품일이 최근인 것부터 위에 나와요. 날짜는 프로젝트 → 제작 기록 탭에서 정해요. 비우면 제출·완료한 작업의 마감일을 쓰고, 둘 다 없으면 맨 아래예요.

## Claude 밖에서 관리할 때 (`#admin`)

- 바꾼 내용은 그 브라우저에만 저장돼요.
- 고객 사이트에 반영하려면 관리 화면 위쪽 **content.js 내보내기** → 폴더의 `content.js`를 받은 파일로 교체 → 다시 업로드.
- 프로젝트(마감일·메모)는 공개 파일에 들어가지 않아요. **프로젝트 백업**으로 따로 보관하세요.
- 새 사진은 `img` 폴더에 넣고 관리 화면 "사진·영상"에서 파일 이름을 등록하면 사진 목록에 나와요.

## 파일

| 수정할 것 | 파일 |
| --- | --- |
| 상품·문구·배너·연락처·샘플·글꼴 선택 | `content.js` |
| 브랜드 색 | `theme.css` |
| 글꼴 목록 (새 글꼴 추가) | `site.js`의 `FONTS` + `fonts/` 폴더 |
| 고객 화면 스타일·동작 | `site.css`, `site.js` |
| 관리 화면 | `admin.css`, `admin.js` |
| Claude 밖 관리자 저장 | `local-store.js` |
| 사진·로고·아이콘 | `img/` |

다른 AI(ChatGPT 등)에게 맡길 때는 `AI_GUIDE.md`를 먼저 읽게 해 주세요.

## 올리기 전에

- 업로드할 것: 이 폴더 전체 (`index.html`, js·css 파일, `img/`, `fonts/`).
- 사이트에 쓰지 않는 원본 파일(예: 로고 시트 원본 PNG)은 업로드 폴더에서 빼 두면 용량이 줄어요.
- 글꼴(그리운X국한박 고운, 온글잎 윤탱체)은 각 배포처의 라이선스에서 웹사이트 사용이 허용되는지 확인해 주세요.
